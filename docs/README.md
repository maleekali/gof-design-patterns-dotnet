# Documentation Index

This directory contains the project-wide documentation for the GoF Design Patterns in C# and .NET repository.

## Documents

- [Pattern Catalog](pattern-catalog.md): the complete list of 23 Gang of Four patterns, grouped by category, with implementation status and project ideas.
- [Decision Guide](decision-guide.md): practical questions and comparisons to help choose an appropriate pattern without forcing one where a simpler design is sufficient.
- [Learning Roadmap](learning-roadmap.md): the three learning levels, recommended implementation workflow, and definition of done.
- [Pattern README Template](templates/pattern-readme.md): a consistent documentation template for each pattern.

## Documentation Principles

1. Explain the problem before describing the pattern.
2. Show the smallest useful implementation before adding infrastructure.
3. Document alternatives and trade-offs, including when not to use the pattern.
4. Keep claims about implementation status accurate.
5. Add dependencies only when they make the scenario more realistic or testable.
